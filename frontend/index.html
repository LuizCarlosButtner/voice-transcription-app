Como Funciona o Ditado no macOS

O Voice Transcription roda como daemon silencioso no menu bar. Você não precisa manter esta janela aberta para utilizá-lo:

  1. Clique no campo de texto onde quer escrever (WhatsApp, VS Code, Google Docs, Terminal, etc.).
  2. Pressione e segure a tecla ⌥ Option (Alt). O microfone começará a capturar.
  3. Fale normalmente, inclusive fazendo pausas naturais de respiração — o áudio não será cortado.
  4. Solte a tecla. O áudio é enviado para transcrição na nuvem ultra-rápida Groq, tem o tom ajustado e é colado na posição exata do seu cursor.
  5. Pressione Esc caso queira cancelar uma gravação sem colar nada.

Permissões de Sistema Necessárias

Para o macOS permitir que o aplicativo interaja sobre outros programas, conceda as permissões em Ajustes do Sistema > Privacidade e Segurança:

🎙️
Microfone: Permite capturar sua voz quando a tecla for acionada.
♿
Acessibilidade: Permite detectar se há um campo de texto ativo e colar o resultado no cursor.
⌨️
Monitoramento de Entrada: Permite escutar a tecla de atalho mesmo estando em outro app.
